# おみくじ 🐗🌸

イノシシがおみくじを持ってきてくれる、かわいいおみくじアプリです。

## 遊び方

1. 「おみくじを引く」ボタンを押します
2. おみくじの筒がゆれて「ジャラジャラジャラ♪」と音がします
3. イノシシが走ってきて、おみくじを持ってきてくれます
4. 今日の運勢（大吉・中吉・小吉・吉・末吉・凶）と、金運・健康運（★、運勢に合わせて出ます）、ラッキーアイテム、ラッキーカラー、ラッキーナンバー、今日の小さな一歩が出ます

## ルール

- 1日に **1回だけ** しか引けません（何回も引き直すとありがたみが薄れるので）
- 引いたら、その日はおしまいです。また明日引けます

## 使い方（パソコン・スマホ）

`index.html` をブラウザで開くだけで遊べます。インストールはいりません。

## GitHubへの上げ方

1. GitHubにログインして、右上の「＋」→「New repository」を押します
2. Repository name に `inochan-omikuji` と入れて「Create repository」を押します
3. 「uploading an existing file」を押して、このフォルダの中のファイルを全部選びます
4. 「Commit changes」を押せばアップ完了です

## ファイル

- `index.html` … アプリ本体
- `boar.gif` … かわいいイノシシのGIF画像（アプリの中で使います。index.html と同じ場所に置いてください）
- `README.md` … この説明

## イノシシの動きと音

- イノシシが持ってくる紙には、下に出る結果と同じ運勢が書かれます
- 持ってくるときは、いつも走って持ってきます（boar_run.gif）
- 結果が出たときに、その運勢専用の短いGIFに切り替わります（大吉：大きく飛んで後ろ向きに三回転して飛ぶポーズに戻る、中吉：ジャンプ1回、小吉：ゆらゆら揺れる、吉：足をついたまま手を上げるだけ（飛ばない）、末吉：ゆっくりおじぎ、凶：うなだれたまま顔を上げない）
- 凶が出たときだけ、結果が出るときに「ブブー」というがっかり音がします
- 一言と「今日の小さな一歩」は運勢ごとに50通り、ラッキーアイテムは色なしのものだけで運勢ごとに20通り、ラッキーカラーは20色から別にランダムで出て、引くたびにランダムに組み合わさります（凶の言葉は全部、怖くない優しい言葉です）
- ごくまれに特別な当たり「特大の大吉」が出ます（大吉を引いたときの一部）。ファンファーレの音と専用GIFと特別な言葉が出て、金運・健康運は星5つになります
- 結果が出たときに、運勢の名前だけを声で言います（例：「大吉だよ！」）。声は少し高めの可愛い声です。全文の読み上げはしません
- 「おみくじ手帳」のカレンダーに結果が残り、連続で引いた日数が見られます（前の月・次の月も見られます）。カレンダーでは、引いた日のマス全体が運勢の色になります（特大の大吉：金色、大吉：赤、中吉：オレンジ、小吉：黄色、吉：緑、末吉：みずいろ、凶：グレー）。記録はその人の端末の中だけに保存されます
- 開いたときのイノシシの挨拶は、曜日と日にちで変わります（天気のことは言いません）
